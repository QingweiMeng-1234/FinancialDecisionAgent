01 / 调度差异

串行组复用一个 Agent；并行组按上限创建同模板 Agent。两组每次都只传当前公司的材料，避免把上下文差异混入速度比较。

02 / 恢复来自持久化

两组逐项原子保存任务记录。B 超时后只重试 B，A/C 的结果和尝试 ID 保持不变。刷新页面或重启服务后可恢复记录。

03 / 证明范围

本地模拟测调度行为，真实模式仍包含人为检索等待。普通并行模型调用也有加速收益；线程和同进程 Agent 不提供进程级故障隔离。

01 / 单循环也能抢占

Hook 在步骤之间检查事件，保存内存检查点，处理预警后恢复。它不能中断本实验正在执行的步骤；细粒度检查也可能满足期限。

02 / 独立推进有资源成本

独立组使用两个同模板 Agent 和两个异步执行循环。研究与预警可以重叠，但占用额外并发额度；普通 worker 也能实现，不是 Agent 名字带来的收益。

03 / 不是进程隔离实验

三组同进程、并发运行，检查点仅在内存，关闭页面后继续，服务重启即丢失。共享 CPU 或供应商限流时，不保证这里的响应时间；没有真实交易或外部模型费用。
